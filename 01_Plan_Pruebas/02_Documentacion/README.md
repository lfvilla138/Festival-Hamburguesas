# Documentación Técnica y de Usuario

Esta carpeta contiene la documentación funcional y técnica del Sistema de Gestión para Festival de Hamburguesas.

## Contenido

- Manual de Usuario.
- Documentación Técnica.
- Descripción de las tecnologías utilizadas.
- Justificación técnica de las herramientas seleccionadas.

## Objetivo

Facilitar la comprensión, uso y mantenimiento del sistema por parte de usuarios finales y personal técnico.
