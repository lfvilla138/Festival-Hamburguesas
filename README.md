# Sistema de Gestión para Festival de Hamburguesas

## Descripción

Proyecto académico desarrollado para la asignatura Ingeniería de Software.

El objetivo del sistema es facilitar la gestión de restaurantes participantes, control de inventario, registro de ventas y generación de reportes para la administración de un Festival de Hamburguesas.

## Estructura del Repositorio

### 01_Plan_Pruebas
Contiene el plan de pruebas del sistema, incluyendo estrategia de pruebas, casos de prueba y evidencias simuladas de los resultados obtenidos.

### 02_Documentacion
Contiene el Manual de Usuario y la Documentación Técnica del sistema, incluyendo la descripción y justificación de las tecnologías utilizadas.

### 03_Gestion_Post_Proyecto
Contiene la estrategia de seguimiento, soporte y mantenimiento posterior a la entrega del sistema.

### Evidencias
Contiene capturas del tablero Trello y del repositorio GitHub como evidencia del proceso de desarrollo y gestión del proyecto.
